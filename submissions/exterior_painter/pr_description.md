## Project Summary · 项目说明

- **Project name · 项目名称**: Tower painting descent task
- **Robot platform · 机器人平台**: FF Master humanoid from the repository `assets/Master/ff_master_ultra.xml`.
- **Task goal · 任务目标**: Simulate the FF Master robot standing in a moving exterior painting vehicle that descends a tower while a roller touches and paints the building wall.
- **Technical approach · 技术方案**: MuJoCo MJCF scene generation, local FF Master include, generalized-force vehicle descent controller, FF Master floating-base and posture stabilization, contact-aware roller force controller, tower/landing/rail geometry, hand-held roller, paint bucket, swept coverage tracking, and optional video export.
- **Core features · 核心功能**: Top-to-bottom vehicle travel, standing robot worker, measured wall-contact roller force, force-qualified visible paint coverage, viewer mode, headless MP4 export, configurable trip count, and deterministic physics stepping.
- **Highlights · 亮点**: Very legible task, visible painting action, stable automated evaluation, local repository robot model, obvious start/end state, included `demo.mp4`, and explicit `rubric_mapping.md`, `judge_brief.md`, `self_assessment.md`, and `scorecard.json`.
- **Current limitations · 当前局限**: The balance and tool controllers are compact PD-style controllers rather than a learned whole-body policy, and paint is represented as discrete swaths rather than a fluid/material model.
- **Future improvements · 未来改进**: Add richer paint material simulation, learned balance and manipulation policies, camera-based wall segmentation, and longer multi-pass facade tasks.

## How to Run · 如何运行

```bash
cd submissions/exterior_painter
python3 -m venv .venv
source .venv/bin/activate
pip install -e '.[sim]'

# Open the MuJoCo viewer
python -m exterior_painter_robot examples/tiny_house_plan.yaml --owner-goal "paint the tower while riding down" --descent --render

# Headless smoke test
python -m exterior_painter_robot examples/tiny_house_plan.yaml --owner-goal "paint the tower while riding down" --descent --speed 8
```

The smoke test prints contact/coverage evidence such as:

```text
contact-aware paint report: 14/14 swaths covered, 145 contact steps, 100.5 N average roller normal force
```

```bash
# Optional video export on headless Linux
MUJOCO_GL=egl python -m exterior_painter_robot examples/tiny_house_plan.yaml --owner-goal "paint the tower while riding down" --descent --speed 8 --video tower_painting_descent.mp4
```
